## 📌 Overview
 
This repository is a curated collection of my solutions to problems on [TensorTonic](https://www.tensortonic.com), a platform for implementing the core algorithms of machine learning from first principles. Each solution is submitted to and verified by the platform's test suite, then synced here.
 
The goal is not just passing tests. It is to understand *why* each technique works, and where it quietly fails in practice (data leakage, numerical instability, wrong evaluation splits, and so on).
